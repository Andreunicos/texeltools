Why convert game and web images to WebP?

WebP usually produces files 25–35% smaller than PNG or JPEG at similar visual quality, and it supports transparency. Smaller sprites and textures mean faster load times for HTML5 games and websites, which matters most on mobile connections.

What does "Keep original if output is larger" do?

Some images, especially small or already optimized PNGs, can grow when re-encoded. With this option on, the tool keeps the original file in those cases, so a batch never makes anything worse.

Should I use pixel art mode?

Yes, for pixel art that you resize. It keeps hard edges instead of blurring them. For pixel art, PNG or lossless-quality WebP is safer than JPEG.

Are my images uploaded?

No. Conversion uses your browser's own encoders through the HTML5 Canvas API. There is no server and no file limit beyond your device's memory.
