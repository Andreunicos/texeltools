How does the sprite sheet packer work?

Drop the individual frames of an animation (for example run_0.png to run_11.png). The packer places each frame in a cell of a uniform grid, sized to the largest frame, so every frame shares the same dimensions. That is the layout most 2D engines expect for frame-based animation.

Which engines can read the JSON?

The atlas uses the widely supported "JSON Hash" format. Phaser loads it with this.load.atlas() and PixiJS with Assets.load(). Because cells are uniform, you can also load the PNG alone as a fixed-size spritesheet using the cell size shown above.

Why use padding?

When sprites are scaled or filtered, neighboring frames can bleed into each other at the edges. One or two pixels of padding prevents that.

Are my images uploaded?

No. All packing happens locally with the HTML5 Canvas API.
