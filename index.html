What is a normal map?

A normal map is an RGB texture that stores surface direction per pixel. Game engines use it to fake bumps, grooves and detail on flat geometry without adding polygons. This tool reads the brightness of your texture as a height map and converts its slopes into normals using a Sobel filter.

OpenGL or DirectX?

Unity, Blender and Godot use OpenGL-style normal maps (Y+). Unreal Engine and most DirectX pipelines use Y−. Tick "DirectX format" if your lighting looks inverted.

Which format should I export?

Use PNG or high-quality WebP for normal maps: JPEG artifacts distort the normals and create visible lighting noise. For color textures and sprites, WebP usually gives the smallest files at the same visual quality.

Is it private?

Yes. Everything is processed locally with the HTML5 Canvas API. No server ever receives your images.
